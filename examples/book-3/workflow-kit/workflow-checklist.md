# 個人／團隊 Codex 工作流程（複製後裁剪）

## 開始前
- [ ] 任務有唯一目標、排除項和可觀察驗收。
- [ ] 檢查 repo、branch、乾淨狀態和工作區路徑。
- [ ] 確認輸入資料可用於目前工具及帳號政策。
- [ ] 依任務風險選 sandbox 和 approval；外部副作用另外核准。

## 執行中
- [ ] 先讀專案及指出依據，再做最小變更。
- [ ] 每輪要求只涵蓋一項清楚工作；記錄新決策與已驗證結果。
- [ ] Codex 要求離開範圍、連網、安裝或改外部資料時，先停下檢查。

## 驗收
- [ ] 測試執行且非零測試數；錯誤先分辨行為、語法、依賴、環境。
- [ ] 檢查完整 diff，包括新增／未追蹤檔案、資料和秘密。
- [ ] Review findings 逐一重現或合理駁回。
- [ ] 提交只含核准內容；部署另行確認回復計畫。

## 留下交接
- 完成證據：
- 未驗證事項：
- 下一步／負責人：

這是一份流程起點，不是權限設定。依 repo、任務與組織政策調整，不要複製範例就當成安全審批已完成。
